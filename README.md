# Blog API
## Link
https://blog-api-snowy-ten.vercel.app/

## Description
A project that allows you to view different blog posts, login/signup to create an account to post comments with.

## Reflection
This project was good practice decoupling the backend API with various frontends which could consume the backend. Creating an API only backend allowed me to practice creating RESTful endpoints which the frontend could query. Furthermore, it was a good refresher on React while practicing ExpressJS, Prisma, and many other full stack concepts.
